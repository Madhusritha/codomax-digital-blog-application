# Codomax Digital Blog Application

## About the Project
This is a beginner-level Digital Blog Application developed as part of Codomax Module 01 – Frontend Development.

The application allows users to register, log in, create blog posts, view their posts, edit posts, and delete posts.

## Technologies Used
- HTML
- CSS
- JavaScript
- Local Storage

## Pages
1. Home Page
2. Register Page
3. Login Page
4. Dashboard Page
5. Create Blog Page

## Features
- User registration
- User login and logout
- Create blog posts
- View blog posts
- Edit blog posts
- Delete blog posts
- Dashboard with blog post count
- Responsive design

## Project Files
- `index.html` – Home page
- `register.html` – Registration page
- `login.html` – Login page
- `dashboard.html` – User dashboard
- `create-blog.html` – Create blog page
- `style.css` – Website styling
- `script.js` – JavaScript functionality

## How to Run
1. Open the project folder in Visual Studio Code.
2. Install the Live Server extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
